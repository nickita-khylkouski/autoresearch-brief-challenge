# Baseline Research Program

## Objective

Provide a conservative baseline that proves the end-to-end benchmark loop works.

## Strategy

- run a few deterministic searches
- rerank the combined candidate pool
- cite a small set of chunks from distinct sources when possible
- synthesize only from retrieved chunk text

## Non-Goals

- no external APIs
- no hidden heuristics outside the visible submission bundle
- no long-form reasoning output
